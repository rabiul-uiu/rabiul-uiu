Senior Software Engineer at <b>ACI Limited</b> with 6+ years of experience building enterprise financial systems — payment processing, general ledger, and approval workflows — mostly in Laravel and MS SQL Server. Most of my work involves systems where money moves and every transaction has to be traceable, which is what pulled me toward application security. <h3>Security</h3>
<p align="justify">
Application security from a developer's seat — OWASP Top 10 in real Laravel and SQL Server apps: SQL injection, XSS, CSRF, IDOR, and broken access control. I built the credential vault above after getting tired of database passwords sitting in config files, and I review my team's code for authorization enforced at the boundary rather than in the view — the usual failure point in approval-workflow systems. Still growing on the offensive side.
</p>
